# ATLAS — Class 10 Social Science Studio (Josh & Nova)

## Start here
Open `ATLAS_Josh_Nova_2026-27.html` in Chrome, Edge or Firefox. It is a self-contained HTML file and does not need Node.js, npm, a database or a web server. Some image references and the Wikimedia image-search fallback need an internet connection.

## What was merged from the Arena project
- Structured chapter/topic roadmaps for all 22 chapter entries, presented as checkable study routes. These are clearly labelled as learning outlines, not verbatim NCERT contents pages.
- Additional glossary entries to widen revision and active recall.
- Global search now indexes the lesson notes and examples, the chapter route, glossary terms, people, dates, places, and map reminders—not only chapter titles.
- A light/dark theme switch that remembers the setting where local browser storage is available.
- A dedicated Source & Map Desk with official CBSE/NCERT links, assessment-scope warnings, and teacher/learner shortcuts.
- Local chapter-route progress checkboxes where browser storage is available.

## Deliberately not copied as-is
Arena’s upload is a Next.js project. Its source includes only one deeply populated chapter-content JSON file, and some advertised destinations are linked in the UI but do not exist as corresponding app-route pages in the uploaded archive (for example `/present`, `/quiz`, `/maps`, `/teacher`, `/help`, and `/chapters`). The package also includes database setup/seed code. To make the result reliably openable for class, ATLAS remains a static offline-friendly HTML app instead of requiring a development server/database or pretending missing routes are complete.

## Important accuracy rules
- Official reference: CBSE Class X Social Science curriculum 2026–27: https://cbseacademic.nic.in/web_material/CurriculumMain27/SecPart1/SocialScience_SecP1X_2026-27.pdf
- Official textbook portal: https://ncert.nic.in/textbook.php
- Official Class X sample papers/marking schemes 2026–27: https://cbseacademic.nic.in/sqp_classx_2026-27.html
- The current CBSE curriculum identifies The Age of Industrialisation as Periodic Assessment only; the board-exam portion of The Making of a Global World is limited to subtopics 1–1.3; Lifelines of National Economy is map pointing only; Globalisation board theory is limited to the two named topics; Consumer Rights is project work. These limits are flagged in ATLAS.
- The map-work pages in the available 2026–27 curriculum PDF are headed “CLASS X (2025–26)”. ATLAS keeps this mismatch visible and advises confirming the final map list with the teacher.
- ATLAS is a learning companion, not an official CBSE publication. Concept summaries and practice questions are original study aids. Exact textbook examples, tables, maps, quotations, data and assessed scope must be verified against the prescribed NCERT edition and current CBSE notices. The uploaded Arihant guide is scanned and its full text could not be reliably extracted.

## Download / opening help
1. Easiest: open the HTML file directly from this package. If the browser displays it as text instead of a page, right-click the file on your computer and choose **Open with → Chrome/Edge**.
2. To keep it: download or extract the ZIP, then copy the HTML file to your Desktop or a school folder.
3. If the sandbox link opens a preview rather than downloading, use the download icon in the preview, or right-click the link and choose **Save link as**.
4. For best classroom use, open the HTML in a desktop browser and press **Smartboard mode**. Arrow keys move through the slides; Esc exits.
